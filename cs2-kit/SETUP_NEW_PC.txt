다른 PC에서 저장소를 받은 뒤 할 일 (cs2-kit / exllu-103)
================================================================

저장소에는 소스(생성기, YAML, TASK, 사진, 작업 상태)만 있습니다.
게임용 FBX 같은 생성물과 PC별 설정은 일부러 빼 두었으므로 아래를 한 번 실행하세요.
명령은 모두 cs2-kit 폴더에서 실행합니다.

1. 파이썬 패키지 설치 (Python 3.9 이상)

   pip install numpy pillow playwright

   - playwright 는 거리뷰/로드뷰 캡처를 할 때만 필요합니다.

2. Blender 경로 지정 (경로 파일은 PC마다 달라 git에서 제외됨)

   python tools/run_blender.py --set "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe"

   - Blender가 다른 위치에 있으면 그 경로를 넣습니다.
   - Blender 대신 bpy 모듈을 쓰는 방법은 INSTALL.md 참고.

3. 환경 점검

   python tools/agent.py doctor --project exllu-103 --json

4. 게임용 FBX 다시 만들기
   (output/, previews/ 는 크고 다시 만들 수 있어서 저장소에 없음)

   python tools/agent.py cycle --project exllu-103 --generator exllu_103_cs2.py --mode final --json

   - 결과: projects/exllu-103/output/HighriseTower103_L1_5x4/

안 해도 되는 것
---------------
- 사진, 생성기, YAML, TASK.md, photo_refs.json, 작업 상태 파일은 모두 저장소에 있습니다.
- 캡처용 Chrome 프로필(capture/.chrome-vr)은 캡처 도구를 처음 쓸 때 자동으로 만들어집니다.
  로그인 쿠키가 들어 있어서 git에 올리지 않습니다.
- Claude Code 설정과 스킬(.claude/)도 저장소에 있어서, cs2-kit 폴더에서 Claude Code를 열면
  /build, /resume 등을 바로 쓸 수 있습니다.
