- `tools/batch_setup_dongs.py`는 STATUS를 `review:PASS`로, `photo_refs.json`을 조감도 한 장으로 덮어쓰므로 재실행하지 않는다.

- `cs2-kit/.gitignore` 정책상 `projects/*/output/`은 기본적으로 Git 제외 대상이므로(`exllu-103/output/` 기존 추적 파일 예외), 다른 PC에서는 생성기 또는 `cs2-kit/tools/batch_build_all.py`를 다시 실행해 FBX와 뷰어 파일을 생성한다.
- `asset-viewer/editor.js`의 `loadDong()`은 `105~108`은 `_L1_5x6`, 나머지는 `_L1_5x4`를 읽는다.
