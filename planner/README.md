# 🏙️ 한국형 신도시 도로망 & 실시간 교통 시뮬레이터 (CS2 Planner)

## 폴더 안내

- `tests/`: 도로망·차량·브라우저 검증 스크립트
- `screenshots/`: 브라우저 검증 스크린샷
- `reference/`: 도시 조감도 참고 이미지
- `tools/`: 이전 개발 보조 스크립트 (`view3d.js`를 직접 고쳐 쓰는 스크립트이므로 필요할 때만 실행)

Node.js 검증은 이 `planner` 폴더에서 `node tests/test_traffic.js`, `node tests/test_road_network.js`, `node tests/test_roundabout.js`, `node tests/test_simulator.js`로 실행합니다.

시티즈: 스카이라인 2(CS2)를 위한 한국형 신도시(판교·광교·동탄 모델)를 설계하고, 교통 흐름과 병목을 살펴보는 로컬 시뮬레이터입니다.

---

## 🚀 빠른 시작

1. Python 3을 설치하고 이 폴더의 **`신도시_교통시뮬레이터_실행.bat`** 또는 **`run.bat`**을 더블클릭합니다.
2. 로컬 서버가 실행되고 Edge 앱 창 또는 기본 브라우저에서 시뮬레이터가 열립니다.
3. 앱이 켜지면 기본적으로 **"판교/광교형 이상적 신도시 템플릿"**이 자동으로 로드되어 수백 대의 차량이 실시간으로 주행합니다.

---

## 🛠️ 주요 기능

### 1. 🛣️ 계층적 도로망 설계 (Road Hierarchy)
- **주간선대로 (8차선, BRT 황금색)**: 통과 교통 및 광역 축선 (속도 80km/h)
- **보조간선대로 (4차선, 주황색)**: 슈퍼블록 외곽 및 중심상업 연결 (속도 60km/h)
- **생활집산도로 (2차선, 백색)**: 아파트 단지 진입로 및 먹자골목 (속도 30km/h)
- **선형 보행녹지축 (에메랄드)**: 차량 없는 차 없는 보행/수변 산책로

### 2. 🏢 한국형 토지이용 구역 (Zoning)
- **아파트 슈퍼블록 (적색)**: 대단지 아파트 + 초품아(초등학교) 중심 주거지
- **중심상업 & 환승센터 (청색)**: 고밀도 복합몰, 먹자골목, 대중교통 거점
- **테크노밸리 (보라색)**: 첨단 R&D 연구소, 지식산업센터 (직주근접 일자리)
- **수변생태공원 (청록색)**: 신도시 중심을 관통하는 하천 및 공원축

### 3. 🚦 실시간 교통 시뮬레이터 & 병목 감지 (IDM Engine)
- 주거지에서 직장/상업지로 통근하는 가상 차량 실시간 스폰
- 차량 밀도가 높아지면 도로 색상이 **녹색(원활) ➔ 주황(서행) ➔ 적색(체증)**으로 실시간 변화
- 심각한 병목 교차로 발생 시 **우측 대시보드에 긴급 경고 메시지** 표시
- **인스펙터 기능**: 체증이 발생한 도로를 선택하고 **"➕ 1차선 확장"**을 누르면 정체가 즉시 뚫리는 피드백 확인 가능!

### 4. 💾 CS2 연동 (Export JSON)
- 상단 **"💾 CS2 JSON 내보내기"** 버튼을 누르면 본 폴더에 `CS2_NewTown_Layout.json` 파일이 자동 생성됩니다.
- 생성된 JSON을 게임에 적용하려면 해당 형식을 읽는 별도의 연동 수단이 필요합니다. 이 저장소에는 자동 시공 기능이 포함되어 있지 않습니다.
